# Motion data credits

All clips in `canonical/` are processed from class A (open) sources. File-level URLs and sha256
hashes are in `sources.json`; each clip's card repeats its source, licence and credit. These credits
also go in the viewer payload's `meta.notes` when a clip is used.

## CMU Graphics Lab Motion Capture Database
The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with
funding from NSF EIA-0196217. Free for all uses according to the site's statement; the data itself must not be resold.
Licence statement: http://mocap.cs.cmu.edu/

## 100STYLE
I. Mason, S. Starke, T. Komura, "Real-Time Style Modelling of Human Locomotion via Feature-Wise
Transformations and Local Motion Phases", 2022. Zenodo doi 10.5281/zenodo.8127870. CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/).

## Construction Motion Data Library (CML), public version
Tian, Li, Cui, Chen, "Construction motion data library: an integrated motion dataset for on-site
activity recognition", Scientific Data 9, 726 (2022). figshare doi 10.6084/m9.figshare.20480787.v3.
CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Only the in-lab samples are converted.
